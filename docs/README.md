# Willow Lite docs

Willow Lite is an experimental phone OS for the Xiaomi Redmi Note 8 (`willow`): Arch Linux ARM, a Wayland compositor, and a Quickshell touch shell. It is a place to try new interaction ideas, not an Android clone.
